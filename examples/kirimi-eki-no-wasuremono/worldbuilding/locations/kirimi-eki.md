# 霧見駅

## Description

霧見線の終点に近い、木造の小さな駅。単式ホームが一面と、ストーブのある待合室、窓口のついた事務室。駅名標の「霧見」の二文字の下に、最後の日、誰かが手書きの紙を貼った。〈九十年間、ありがとう〉。

## History

大正十五年開業。平成二十八年三月二十五日の最終列車をもって、霧見線とともに廃止される。

## Culture & Customs

雪の朝は、駅員の大島が誰より先にホームを掃く。窓口の奥の菓子缶には、持ち主の来ない預かりものがしまってある。

## Notable Features

- 一両だけの気動車が止まる単式ホーム
- ストーブのある待合室
- 事務室の棚の、平たい菓子缶

## Current State

最終列車の夜。ホームの明かりがひとつずつ消えていく。
