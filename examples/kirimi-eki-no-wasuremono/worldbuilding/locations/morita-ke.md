# 森田家

## Description

駅前の坂を上りきったところにある、古い木造の平屋。玄関の鍵は、郵便受けの裏の釘に掛けてある。台所の棚には湯のみが四つ、伏せたまま並んでいる。

## History

ふみが嫁いできてから亡くなるまで暮らした家。夫の死後四十年、ふみはここでひとりで暮らした。

## Culture & Customs

ものの置き場所は、ふみが生きていたころから何ひとつ変わっていない。

## Notable Features

- 茶の間の箪笥。いちばん下の引き出しの奥に、昭和六十一年の時刻表
- 八時を打つ柱時計
- 石油ストーブ

## Current State

ふみの死後、冬じゅう誰も住んでいない。遥が片づけに来る。
