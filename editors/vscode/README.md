# Story Skills for VS Code

Runs the `story` language server on the markdown files of a [Story Skills](https://github.com/danjdewhurst/story-skills) project: continuity, link, and frontmatter findings as you type, go to definition, find references, hover, id completion, rename, and quick fixes.

It needs the `story` command on your `PATH`, or the `story.server.command` and `story.server.args` settings pointed at another way to run it. [Editor integration](https://github.com/danjdewhurst/story-skills/blob/main/docs/editors.md) explains how to build and install the extension and what each feature does.
