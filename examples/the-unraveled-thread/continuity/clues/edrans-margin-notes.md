# Edran's Margin Notes

## Clue

Edran's handwriting fills every margin of the ledger. Read as bookkeeping, it is only a dead partner's habit; read against the mill's delivery dates, it is a schedule.

## Planting Plan

Chapter 1 shows the margins in passing, in the same sentence as the sealed letter, so the letter takes the reader's attention.

## Payoff Plan

At the lock gate Edran tells Jonas which page mattered, and the margin notes on that page become the schedule of the fire.
