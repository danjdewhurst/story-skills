# 青い封筒

## Description

宛名は〈森田ふみ様〉。切手はなく、裏には何も書かれていない。封は糊づけされていない。

## Function

中身は、使われていない霧見発札幌行きの切符一枚（昭和六十一年二月十四日、十四時五分発）と、〈待っています。〉とだけ書かれた便箋一枚。

## History

昭和六十一年二月、若い男が窓口に来て、森田ふみに渡してくれと大島に預けた。ふみは何日も駅に来たが、一度も窓口には来なかった。大島は三十年、事務室の菓子缶にしまっておいた。

## Current State

最終列車の夜、大島が遥に渡した。
